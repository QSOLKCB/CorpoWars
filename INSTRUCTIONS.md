# Field manual

You control VEX, NULL, ECHO, and IRON. Keep the team together, use corners to
break enemy sightlines, and pause when issuing orders. Guns fire and reload
automatically unless Hold fire is enabled.

## Hostile Takeover

1. **Sever the uplink:** reach the relay and hold beside it for three seconds.
2. **Acquire the ledger:** reach the debt terminal and hold for five seconds.
   Security reinforcements arrive when the records are acquired.
3. **Leave no one behind:** bring every surviving agent within three tiles of
   the extraction point for two seconds.

Objective buttons issue movement orders to the selected agents and focus the
camera on the destination. They do not complete objectives automatically.
At least one stationary living agent with a clear sightline must hack a
terminal; moving away slowly reduces partial progress. Losing the whole squad
ends the mission. You can win with casualties, but extraction requires all
remaining survivors. Completed runs record their best time locally if allowed.

## Controls

| Input | Action |
| --- | --- |
| Click or right-click open ground | Move selected agents in formation |
| Click an agent / squad card; 1–4 | Select an agent |
| Shift + select | Add agents to the selection |
| Drag a box on the battlefield | Select agents inside the box |
| A / Select all | Select all surviving agents |
| Click a visible hostile | Approach and focus fire |
| Space / Pause | Freeze time; movement orders can still be issued |
| Escape | Stop selected agents |
| Arrow keys / middle-button drag | Pan camera |
| F / focus button | Centre selected agents |
| Scroll / + / − / zoom buttons | Zoom |
| T / Cutaway | Hide tall building geometry |
| H / Fire at will | Toggle automatic fire |
| M / Patch | Heal injured selected agents, up to 55 HP each |
| X / EMP | Stun guards within seven tiles of selected agents for six seconds |
| ? / Field manual | Open help; pauses the active mission |
| Sound | Toggle synthesised audio |

Two patches and two EMP discharges are available per mission. Neither can be
used while paused. Patches do not revive fallen agents. EMP can pass through
buildings; gunfire cannot. Ammunition replenishes through automatic reloads.

On touchscreens, tap an agent/card to select, tap terrain to move, and use the
objective, focus, zoom, ability, pause, and minimap controls. The minimap shows
buildings, objective positions, living agents, and currently detected hostiles.
Cars are ambient scenery and cannot be controlled or targeted.

Open the Field manual and choose Restart mission to reset. Reloading the page
also restarts; in-progress mission saves are not implemented.
