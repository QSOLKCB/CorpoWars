# Roadmap

## Slice 1 · v0.1.0 — Playable foundation

- [x] Original procedural city and native WebGL2 renderer
- [x] Four-agent squad, wall-aware combat, pathfinding and patrols
- [x] Complete relay → ledger → extraction mission
- [x] Tactical pause, medical patches, EMP and sound effects
- [x] Simulation and Chromium checks; GitHub Pages delivery

## Slice 2 · delivered in v0.3.0 — Arsenal and research

- [x] Finite 6,000-credit starting budget and per-agent weapon ownership
- [x] Owen Gun, three-mode AUG, fast-reloading Over & Under shotgun
- [x] Prerequisite-gated medical, body augmentation and panic research
- [x] Rechargeable panic retreat behaviour instead of persuasion
- [x] Budget, save validation, reload and retreat regression coverage

## Slice 3 · delivered in v0.3.0 — Campaign and feel

- [x] Ghost Shift and Boardroom Blackout: two more complete contracts
- [x] Three district layouts, ordered unlocks, one-time rewards, local progression
- [x] Relaxed and Hostile difficulty, preserving the original relaxed balance
- [x] WASD / mouse panning, Q select-all, follow camera
- [x] Top-left radar and compact objectives, no desktop HUD scrolling
- [x] Movement interpolation, reusable graphics buffers and visual feedback
- [x] Original mathematical tracker soundtrack with independent audio controls
- [x] Pages deployment gated on simulation and full Chromium campaign checks

## Slice 4 · delivered in v0.4.0 — Hostile Expansion

- [x] Signal Siege, Witness Protection and Golden Parachute
- [x] Three new connected district layouts with distinct procedural visuals
- [x] Contested transmission, bounded security waves, vulnerable courier escort and lockdown deadline
- [x] Bulwark and Marksman enemy roles with readable silhouettes
- [x] Three optional badges per contract/difficulty, without duplicate credit payouts
- [x] Existing v1 campaign save continuity and six-contract progression
- [x] Mission HUD, courier radar/escort controls and debrief challenge results
- [x] Simulation failure/boundary tests and packaged browser expansion playthroughs

## Slice 5 · delivered in v0.4.1 — Human Resources

- [x] Faceted character silhouettes, articulated limbs and readable equipment
- [x] Rounded helmets, segmented visors, curved Bulwark shields and courier case
- [x] Soft contact shadows within existing role geometry budgets
- [x] Same render batches/shaders with measured work and startup observations
- [x] Exact city/tactical stream checks and native before/after visual galleries

## Next

- [ ] In-mission saves and replayable command logs
- [ ] Cover, suppression, civilian behaviours and noncombat mission variants
- [ ] Physical mobile, Firefox, Safari and multiple GPU/driver validation
- [ ] Branching territory campaign beyond the six current districts
- [ ] Controllable vehicles, interiors and vertical traversal
- [ ] Destructible structures and map editing

Unchecked items are proposals, not existing features or release promises.
Preserve independent code/assets, the small runtime, and testable simulation.
