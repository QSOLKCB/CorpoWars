# Roadmap

## v0.1.0 — Playable foundation

- [x] Original procedural city and WebGL2 renderer
- [x] Four-agent squad, navigation, visibility and combat
- [x] Patrol AI, three-stage mission, extraction, victory and failure
- [x] Tactical pause, squad abilities and synthesised effects
- [x] Automated simulation and browser checks; GitHub Pages workflow

## Next: deepen and validate the tactical layer

- [ ] Additional original maps and longer missions with multiple approaches
- [ ] Explicit weapon loadouts, research and squad upgrades
- [ ] Difficulty selection, better pursuit AI, cover and suppression
- [ ] Civilian behaviours and noncombat objectives
- [ ] Versioned mission saves and replayable command logs
- [ ] Physical mobile, Firefox, Safari and multiple GPU/driver validation
- [ ] Optional Canvas 2D renderer for devices without WebGL2

## Later: city and campaign systems

- [ ] Territory map, corporate economy and campaign progression
- [ ] Controllable vehicles, interiors and vertical traversal
- [ ] Destructible structures with routing/visibility updates
- [ ] Map editor and documented asset pipeline

These are proposals, not existing features or release promises. Preserve the
independent code/assets boundary, small runtime, and testable simulation.
